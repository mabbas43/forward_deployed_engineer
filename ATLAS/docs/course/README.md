# The ATLAS course

This folder contains the course this repo implements. It was reconstructed from the original chat,
"LLMOps and adaptive agents with LangChain". **The course documents are the syllabus; the code in `atlas/` is the
reference implementation.** Follow the course rule: build each phase yourself first, then compare.

| File | What |
|---|---|
| `00-complete-course.md` | The full 9-phase course: mental models, concepts, resources, labs, drills, checkpoints with answer keys, gates |
| `01-orientation-and-phase-1.md` | Deep Orientation + Phase 1 guide: milestones M0.1–M1.8, day-by-day, code, drills |
| `02…09-phase-N.md` | Deep guide per phase: goal, Mermaid diagram, concepts, ranked resources, milestones, labs, Level 2, drills, checkpoint, gate |
| `10-advanced-tracks.md` | After v1.0: fine-tuning/serving, multimodal retrieval, A2A, voice, Deep Agents |
| `11-strategy-3-months.md` | "Signal over noise": 6 deep hours, one project, publish every Friday, real gates |
| `12-job-roles.md` | Which roles each phase qualifies you for (German market) |
| `13-phase-1-operating-procedure.md` | Exactly how to run the Phase 1 week, plus `rules.md` / `phase1.md` templates |
| `99-first-draft-syllabus.md` | The first, shorter syllabus (kept for history) |
